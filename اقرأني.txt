مجلد تطوير لعبة الكرة الحمراء 3D

الملف الرئيسي: index.html

طريقة التشغيل:
- افتح index.html باستخدام Chrome أو Edge أو Safari.
- اللعبة تعمل مباشرة ولا تحتاج إلى تثبيت برامج أو مكتبات.

التحكم:
- الكمبيوتر: الأسهم أو A و D للحركة، والسهم للأعلى أو W أو المسافة للقفز.
- الجوال: استخدم أزرار اللمس أسفل الشاشة.

المحتويات المدمجة:
- لعبة عدّاء ثلاثية الأبعاد بثلاثة مسارات وعشرة عوالم تتدرج في الصعوبة.
- قفز وانزلاق واندفاع، وأشواك وصناديق وطائرات مسيّرة وبلورات قابلة للجمع.
- يُطلب اسم اللاعب قبل بدء اللعب، وتُحفظ أفضل النتائج محليًا عند غياب قاعدة البيانات.
- ربط اختياري بلوحة متصدرين عالمية باستخدام Supabase؛ راجع supabase-schema.sql.
- تحكم بلوحة المفاتيح وأزرار لمس، وتصميم متجاوب مع الجوال والاتجاه الأفقي.
- يتطلب عرض اللعبة اتصالًا بالإنترنت لتحميل محرك Three.js من CDN ودعم WebGL.

إعداد سجل النقاط العالمي:
1. أنشئ مشروعًا مجانيًا في Supabase.
2. افتح SQL Editor في لوحة المشروع، والصق محتويات supabase-schema.sql، ثم شغّلها.
3. من إعدادات API في Supabase، انسخ Project URL وPublishable (anon) key.
4. ضع القيمتين في SUPABASE_URL وSUPABASE_ANON_KEY أعلى ملف index.html.
   المفتاح publishable/anon مصمم للاستخدام في المتصفح؛ لا تضع service_role أو
   أي مفتاح سري في ملفات الموقع.
5. انشر index.html وsupabase-schema.sql على GitHub Pages.

من دون هذه الخطوات، تبقى لوحة الترتيب محلية على الجهاز ولا تُشارك بين اللاعبين.

للتطوير:
- افتح index.html في محرر نصوص مثل Visual Studio Code.
- عدّل CSS داخل <style> لتغيير التصميم.
- عدّل JavaScript داخل <script type="module"> لتغيير اللعب والمراحل.
- احتفظ بنسخة احتياطية قبل التعديلات الكبيرة.
