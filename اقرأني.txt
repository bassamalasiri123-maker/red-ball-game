مجلد تطوير لعبة الكرة الحمراء 3D

الملف الرئيسي: index.html

طريقة التشغيل:
- افتح index.html باستخدام Chrome أو Edge أو Safari.
- اللعبة تعمل مباشرة ولا تحتاج إلى تثبيت برامج أو مكتبات.

التحكم:
- الكمبيوتر: الأسهم أو A و D للحركة، والسهم للأعلى أو W أو المسافة للقفز.
- الجوال: اسحب أفقيًا لتغيير المسار، للأعلى للقفز، وللأسفل للانزلاق؛ انقر مرتين للاندفاع. لا تظهر أزرار التحكم أثناء اللعب باللمس، وتختفي أدوات اللعب في القائمة الرئيسية.
- لوحة المفاتيح: Shift للاندفاع، والأسهم أو A و D لتغيير المسار، والسهم للأسفل أو S للانزلاق.

المحتويات المدمجة:
- لعبة عدّاء ثلاثية الأبعاد بثلاثة مسارات و50 مرحلة، طول كل منها 400 وحدة، موزعة على أربعة أقسام صعوبة: البداية (1–13)، التحدي (14–26)، الخبرة (27–38)، والأساطير (39–50). يمكن اختيار أي قسم ومرحلة مباشرة من القائمة.
- تزداد سرعة اللعب 0.02 مع كل مرحلة، كما تزداد موجات العوائق واحتمالية ظهور عائق إضافي تدريجيًا من المرحلة الأولى حتى الخمسين. تظهر مواجهة حارس في نهاية كل قسم عند المراحل 13 و26 و38 و50.
- قفز وانزلاق واندفاع، وأشواك وصناديق وطائرات مسيّرة وألغام وفخاخ موحّدة باللون الأحمر، وبلورات قابلة للجمع.
- خلفيات جبلية ثلاثية الأبعاد أكثر تفصيلاً مع قمم ثلجية وأشجار صنوبر وشجيرات خضراء، مستوحاة من معالم عالمية مثل إيفرست وماترهورن وفوجي وكليمنجارو، مع ألوان وأجواء مختلفة للأقسام وكاميرا أبعد لإظهار المشهد.
- قوى قابلة للجمع: الدرع يصد ضربة واحدة، والمغناطيس يجذب البلورات القريبة بحركة مرئية، والساعة تبطئ اللعب مؤقتًا.
- مهام يومية وإنجازات تُحفظ محليًا في المتصفح، وتبقى متاحة للضيف دون إدخال اسم.
- الاسم اختياري: يمكن اللعب كضيف دون حفظ النتيجة، أو إدخال اسم لحفظ أفضل نتيجة محليًا وعرضها في لوحة المتصدرين العالمية.
- ربط اختياري بلوحة متصدرين عالمية باستخدام Supabase؛ راجع supabase-schema.sql.
- وجه مرسوم على خامة كروية مرتبطة بالكرة، فتدور ملامحه معها بدل أن تطفو منفصلة.
- اختيار واحد من ١٠ أشكال للكرة من القائمة قبل اللعب، مع حفظ الشكل المختار على الجهاز.
- مؤثرات صوتية مولدة داخل المتصفح للقفز والانزلاق والاندفاع وجمع البلورات والقوى والاصطدام وإنهاء المرحلة.
- الكرة تلامس سطح الطريق أثناء التدحرج؛ وعند الانزلاق ينخفض مركزها ليلائم انضغاطها، مع ظل على مستوى الطريق.
- جميع الفخاخ باللون الأحمر المتوهج، بأشكال مسننة موحدة الطابع.
- تحكم بلوحة المفاتيح وإيماءات اللمس، وتصميم متجاوب مع الجوال والاتجاه الأفقي.
- يتطلب عرض اللعبة اتصالًا بالإنترنت لتحميل محرك Three.js من CDN ودعم WebGL.

النقاط:
- نقطة واحدة لكل مترين، و3 نقاط لكل بلورة، و120 نقطة لكل مرحلة مكتملة.
- الحد النظري الأقصى للتصميم الحالي 21,973 نقطة عند جمع كل البلورات وإنهاء المراحل الخمسين بدءًا من المرحلة الأولى؛ لذلك يبقى ضمن حد قاعدة البيانات 52,000.

إعداد سجل النقاط العالمي:
1. أنشئ مشروعًا مجانيًا في Supabase.
2. افتح SQL Editor في لوحة المشروع، والصق محتويات supabase-schema.sql، ثم شغّلها.
3. من إعدادات API في Supabase، انسخ Project URL وPublishable (anon) key.
4. ضع Project URL وPublishable key في SUPABASE_URL وSUPABASE_ANON_KEY
   أعلى ملف index.html. المفتاح Publishable مصمم للاستخدام في المتصفح؛ لا تضع
   service_role أو أي مفتاح سري في ملفات الموقع.
5. انشر index.html وsupabase-schema.sql على GitHub Pages.

قاعدة البيانات الحالية تقبل المراحل 1–50 والنتائج حتى 52,000، ولا تحتاج ترقية إضافية مع معادلة النقاط الحالية. عند إعداد مشروع جديد أو تحديث قاعدة قديمة، شغّل supabase-schema.sql في SQL Editor.

المشروع الحالي مرتبط بقاعدة Supabase فعلية مع سياسات RLS وواجهة آمنة لحفظ
أفضل نتيجة لكل اسم. ملف SQL ينشئها بأمان عند إعداد مشروع جديد. ضع حدًا للنقاط
المقبولة في جهة الخادم إذا تغيّرت قواعد احتساب النقاط في اللعبة.

للتطوير:
- افتح index.html في محرر نصوص مثل Visual Studio Code.
- عدّل CSS داخل <style> لتغيير التصميم.
- عدّل JavaScript داخل <script type="module"> لتغيير اللعب والمراحل.
- احتفظ بنسخة احتياطية قبل التعديلات الكبيرة.
